## Featured projects

* **Physical AI opportunities for Schneider Electric**: field consulting project; scored 45 use cases across 11 sectors in an Excel model and recommended technology partners
* **Can you trust an AI with records?**: 1,590 automated Python tests of GPT-5.4 and gpt-5.4-mini on 418,947 CMS nursing-home records; accuracy fell from 96% to 17% on long lists
* **Building and fine-tuning a small language model**: pretrained a nano-BERT on WikiText-2, fine-tuned it on DrugLib reviews, benchmarked against bert-base-uncased (Python)
* **H-1B policy and Boston-area mobility**: Tableau analysis of 65,360 place-month foot-traffic records from Advan data
* **Predicting medical insurance charges**: multiple regression in R (adjusted R² 0.749, n = 1,338)
* **Warehouse stocking plan (supply chain optimization)**: Python linear programming for warehouse inventory allocation, presented in Power BI
* **DeisHacks 2026: SVP Boston, Activating Impact Through Data**: team hackathon build with a SQLite database, a Python Flask web app and a Tableau dashboard ([Devpost](https://devpost.com/software/svp-boston-activating-impact-through-data))
* **Tesla supplier audit analysis**: value stream mapping under the SSCI framework
* **EV traceability tools**: Java and SQLite tools from my Endurance Technologies internship
