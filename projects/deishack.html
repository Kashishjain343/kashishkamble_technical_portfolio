SVP Boston: Activating Impact Through Data

A hackathon build that gives SVP Boston one place to keep information about its nonprofit partners, a simple web app to update it, and a Tableau dashboard to analyze it.

My part: I built the SQLite database, the single source of truth behind the web app and dashboard.

The idea: Store the data once, let staff update it without touching code, and point a dashboard at it so the numbers are always current.

The problem

Information about SVP Boston's nonprofit partners needed a single, reliable home, plus an easy way to both update it and analyze it.

What we built

A SQLite database as the single source of truth, built in DB Browser for SQLite. A Python Flask web app with SQLAlchemy lets users edit the records, with the DataTables library making the table easy to search and sort. A Tableau dashboard sits on top for analysis.

Working without the real data

We didn't have access to SVP Boston's actual records, so we used ChatGPT to generate realistic sample data as a starting point. The dashboard is built to be customized once the real data is plugged in.

What I took away

Setting up a SQLite database, building a web app with Flask, and creating visualizations in Tableau, all during the hackathon as a team of three, combining each person's strengths into one working solution.
