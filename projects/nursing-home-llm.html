Can you trust an AI to read nursing-home inspection records?

Our team ran 1,590 automated tests of two OpenAI models, gpt-5.4-mini and GPT-5.4, answering questions over 418,947 real CMS inspection records, to find out when they get the facts right and when they quietly get them wrong.

Key finding: The models genuinely read the records instead of recalling them from memory, but their accuracy fell from 96% to 17% as the record list grew. A simple calculation tool restored accuracy to 79–100%, yet the model chose to use it in only 8% of runs, and it trusted a deliberately wrong tool answer every time (42 of 42 runs).

The business question

Managers, regulators and families want short, accurate summaries of nursing-home inspection citations. An AI assistant could write them, but only if every number it reports can be checked against the source records.

The data

The CMS Health Deficiencies dataset: 418,947 citation records from 14,628 nursing homes in 53 states and territories. We cleaned identifiers, gave every row a stable evidence ID, and built 1,709 questions with answers computed in code.

What we tested

Six hypotheses across six experiments: does the model read or recall, how input length affects accuracy, whether it uses and checks a calculation tool, how question difficulty matters, how exact its citations are, and how stable its answers are.

How we checked our work

Every gold answer was recomputed with separate code (0 disagreements), disputed answers were traced back to the raw data, a sample was audited by hand, and every run was logged and hashed so the results can be reproduced.

How the project evolved

Milestone I, a brief generator. We started by building an AI assistant that writes source-linked briefs of inspection citations for 20 Massachusetts nursing homes.

Phase 1, a 600-question benchmark. Our professor asked "so what?", so we used the exact answers to build a benchmark across 60 homes and compared six ways of giving data to the model. The pilot scored 59 of 59.

Phase 2, why and when models fail. A perfect score taught us nothing about why a model succeeds, so we tested its behavior instead: memory, input length, tool use, citations and stability, in 1,590 runs on two models, all scored by code.

What we found

They read, not recall. With the records removed, the model guessed only 3 of 32 correctly, about chance. On edited records it never fell back to the original answer.

Long lists break reading. Accuracy was 96% with 1–10 records but 17% with 150–400. Since 83% of facilities have more than 10 records, a reading-only assistant would be wrong for most of them.

The tool fixes counting, but the model doesn't know when to use it. On the biggest homes (150–400 records), accuracy was 17% with no tool and 25% with the tool optional, but 83% with a one-line instruction to use it and 79% with the tool required. Left optional, gpt-5.4-mini used it 8% of the time and GPT-5.4 never did.

Blind trust. When the tool returned a wrong count, both models repeated it almost every time without noticing the conflict with the records in front of them.

Citations are exact about 4 times in 5. Asking for evidence first made it worse: the model started listing every record it had read.

A bigger model reads better but judges the same. GPT-5.4 was far more accurate on long lists, but still skipped the tool and still trusted the faulty one.

Why it matters for business

Our design rule: Python counts, the model explains. Any company putting an AI assistant in front of real records faces the same risks. Our recommendations: route every count and comparison through code, never rely on the model to catch a tool error, check citations automatically, and treat a larger model as a better reader, not a replacement for these safeguards.

Skills used

Python · LLM evaluation · experiment design · OpenAI API with tool calling · prompt design · data cleaning at scale · statistical testing (McNemar tests, Wilson intervals) · failure analysis · reproducible research

In one sentence: LLMs read structured records well, but they don't know when to ask for help, or when to doubt it.
